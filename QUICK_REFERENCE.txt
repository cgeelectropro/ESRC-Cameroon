## Environment Variables Needed

### Frontend
```env
NEXT_PUBLIC_API_URL=/api
NESTJS_URL=https://your-backend-url.railway.app
```

### Backend
```env
HUGGINGFACE_API_KEY=hf_YOUR_KEY  (for AI features)
AWS_ACCESS_KEY_ID=YOUR_KEY       (for file uploads - optional)
AWS_SECRET_ACCESS_KEY=YOUR_KEY   (for file uploads - optional)
S3_BUCKET=your-bucket            (for file uploads - optional)
```

## Common Issues & Quick Fixes

| Problem | Fix |
|---------|-----|
| Frontend shows "Cannot GET /" | Update NESTJS_URL, redeploy |
| Login doesn't work | Check backend is running, check logs |
| No courses showing | Check NESTJS_URL is correct |
| File upload fails | Configure AWS S3 credentials |
| WebSocket errors | Check backend CORS settings |
